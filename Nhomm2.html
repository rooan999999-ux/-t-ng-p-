Local scope – Global scope – Ứng dụng thực tế

1. Biến trong hàm vs ngoài hàm

📦 Biến trong hàm (Local)

  • Khai báo bên trong thân hàm (kể cả tham số)
  • Chỉ tồn tại khi hàm đang chạy
  • Bị xóa khỏi bộ nhớ sau return
  • Bên ngoài hàm không thể truy cập

🌍 Biến ngoài hàm (Global)

  • Khai báo ở đầu file, ngoài mọi hàm
  • Tồn tại xuyên suốt chương trình
  • Mọi hàm đều có thể đọc được
  • Muốn ghi đè trong hàm → dùng global

Ẩn dụ dễ nhớ: Biến local như đồ dùng cá nhân trong phòng họp kín – chỉ người trong phòng dùng. Biến global như đồ trong sảnh công ty – ai cũng thấy, nhưng muốn thay đổi phải có sự cho phép (từ khóa global).

Ví dụ 1: Local bị "cô lập"

local_demo.py
def tinh_tong(a, b):
    ket_qua = a + b   # Biến local
    return ket_qua

tinh_tong(5, 3)
# print(ket_qua)  # ❌ NameError: name 'ket_qua' is not defined

✅ Giải thích: ket_qua chỉ sống bên trong tinh_tong. Khi hàm kết thúc, biến bị thu hồi. Ra ngoài, Python không còn nhận diện được → báo lỗi.

Ví dụ 2: Che khuất biến toàn cục

shadowing.py
pi = 3.14159   # Biến toàn cục

def thay_doi_pi():
    pi = 3.14    # Tạo biến local mới, không ảnh hưởng global
    print("Trong hàm:", pi)

thay_doi_pi()          # In ra: 3.14
print("Ngoài hàm:", pi) # In ra: 3.14159 (không đổi)

🔍 Giải thích: Khi gán pi = 3.14 bên trong hàm, Python hiểu là tạo biến local mới (hiện tượng shadowing). Biến toàn cục pi vẫn giữ nguyên giá trị.

👉 Muốn sửa biến global, cần khai báo global pi trước khi gán.

3. Thực hành: Lỗi UnboundLocalError

Đề bài: Biến toàn cục count = 10. Hàm increase() tăng count lên 1. Tại sao lỗi?

count = 10

def increase():
    print(count)   # Dòng này gây lỗi
    count = count + 1

increase()

❌ Lỗi: UnboundLocalError: local variable 'count' referenced before assignment

Nguyên nhân: Python thấy phép gán count = ... bên trong hàm → coi count là biến cục bộ. Nhưng dòng print(count) lại cố gắng in biến cục bộ chưa được khởi tạo.

Cách sửa: Thêm global count ở đầu hàm.

Sửa lỗi với từ khóa global

count = 10

def increase():
    global count   # Báo Python: dùng biến toàn cục
    print(count)   # In ra 10
    count = count + 1

increase()
print("Sau khi tăng:", count)  # In ra 11

Bây giờ chương trình chạy đúng. Biến toàn cục count được cập nhật thành 11.

⚠️ Lưu ý: Chỉ dùng global khi thực sự cần thiết, tránh làm code khó bảo trì.

4. Sáng tạo: Hệ thống quản lý điểm & đếm hành động

Mở rộng từ bài thực hành: thêm tính năng đếm số lần thêm học sinh và tính điểm trung bình.

# Biến toàn cục lưu trạng thái
tong_so_lan_them = 0
tong_diem = 0.0
so_hoc_sinh = 0

def them_hoc_sinh(ten, diem):
    global tong_so_lan_them, tong_diem, so_hoc_sinh
    tong_so_lan_them += 1   # tăng số lần gọi
    if diem < 0 or diem > 10:
        return f"❌ {ten}: điểm {diem} không hợp lệ"
    tong_diem += diem
    so_hoc_sinh += 1
    return f"✅ Đã thêm {ten} | Điểm: {diem}"

def diem_trung_binh():
    return tong_diem / so_hoc_sinh if so_hoc_sinh > 0 else 0

# Chạy thử
print(them_hoc_sinh("An", 8.5))
print(them_hoc_sinh("Bình", 9.0))
print(them_hoc_sinh("Chi", -5))   # không hợp lệ
print(f"Số HS: {so_hoc_sinh}, ĐTB: {diem_trung_binh():.2f}")
print(f"Tổng số lần gọi hàm: {tong_so_lan_them}")

Giải thích bài sáng tạo

Biến toàn cục

  • tong_so_lan_them: đếm số lần hàm được gọi (kể cả lỗi)
  • tong_diem, so_hoc_sinh: lưu dữ liệu xuyên suốt

→ Cần global vì nhiều hàm cùng đọc/ghi.

Biến cục bộ

  • Tham số ten, diem: chỉ dùng trong hàm
  • Không có biến local nào lưu trữ lâu dài

→ Tiết kiệm bộ nhớ, không ảnh hưởng ra ngoài.

🎯 Ý nghĩa thực tế: Hệ thống có thể mở rộng thành ứng dụng quản lý học sinh, ghi log số lần thao tác để kiểm tra hiệu suất hoặc phát hiện bug.

📌 Tổng kết

  • Biến trong hàm (local) – chỉ dùng nội bộ, an toàn, tự động hủy.
  • Biến ngoài hàm (global) – chia sẻ toàn chương trình, cần global để sửa.
  • Lỗi thường gặp: UnboundLocalError khi vừa đọc vừa gán biến cùng tên.
  • Nguyên tắc vàng: Ưu tiên local, hạn chế global trừ khi cần lưu trạng thái xuyên suốt.
