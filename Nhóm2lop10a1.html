Biến trong hàm (Local) & Ngoài hàm (Global)

Sơ đồ tư duy

PHẠM VI BIẾN
Trong hàm (Local)
  • Khai báo bên trong hàm
  • Chỉ dùng được trong hàm đó
  • Tự xóa sau khi hàm chạy xong
Riêng tư
Ngoài hàm (Global)
  • Khai báo bên ngoài mọi hàm
  • Dùng được toàn chương trình
  • Tồn tại xuyên suốt quá trình chạy
Dùng Chung

🎯 Ghi nhớ nhanh: Local → Riêng tư | Global → Chung

So sánh nhanh

Tiêu chí Biến Local Biến Global
Vị trí khai báo Bên trong hàm Bên ngoài hàm
Phạm vi hoạt động Hạn chế (nội bộ) Toàn chương trình
Thời gian sống Tạm thời Lâu dài
Quyền truy cập Chỉ trong hàm đó Mọi nơi

👉 Kết luận: Nên ưu tiên dùng Local để tránh lỗi và dễ quản lý hơn. Chỉ dùng Global khi cần chia sẻ dữ liệu.

Câu hỏi tương tác

Các bạn hãy đoán kết quả khi chạy đoạn code sau:

quiz.py
count = 5

def test():
    count = 10
    print("Trong hàm:", count)

test()
print("Ngoài hàm:", count)

👉 Kết quả sẽ là gì?

Trong hàm: 10
Ngoài hàm: 5

💡 Giải thích: Khi viết count = 10 trong hàm, Python tạo ra một biến Local mới trùng tên, hoàn toàn không ảnh hưởng đến biến Global bên ngoài.

Lỗi phổ biến: UnboundLocalError

Cố gắng thay đổi biến Global từ bên trong hàm nhưng quên khai báo:

error.py
score = 0

def tang_diem():
    score = score + 10  # 💥 Gây lỗi tại đây!
    print(score)

tang_diem()

UnboundLocalError: local variable 'score' referenced before assignment

Python coi `score` là biến cục bộ (vì có phép gán =), nhưng nó chưa có giá trị ban đầu để cộng thêm 10.

Giải pháp: Từ khóa global

Để sửa lỗi, ta phải nói cho Python biết: "Hãy dùng biến ở ngoài kia!"

fixed.py
score = 0

def tang_diem():
    global score        # ✅ Báo hiệu dùng biến Global
    score = score + 10
    print("Điểm hiện tại:", score)

tang_diem()  # Output: Điểm hiện tại: 10
tang_diem()  # Output: Điểm hiện tại: 20

Lưu ý: Chỉ dùng global khi thực sự cần thay đổi giá trị. Nếu chỉ đọc thì không cần.

Ứng dụng thực tế

Trong Game

Dùng biến Global để lưu Điểm số (Score), Máu (HP) xuyên suốt các màn chơi.

Trong Web

Đếm tổng số lượt truy cập hoặc số người đang online trên toàn hệ thống.

Trong App

Lưu trạng thái đăng nhập của người dùng (Token/Session) để các màn hình khác nhận diện.

👉 Global: Lưu dữ liệu trạng thái lâu dài.
👉 Local: Xử lý logic tạm thời bên trong các nút bấm, chức năng.

Hệ thống quản lý thực tế

Kết hợp cả Local (tham số) và Global (lưu trữ) một cách chuyên nghiệp.

school_system.py
# Biến Global: Lưu trữ trạng thái hệ thống
tong_diem = 0.0
so_hoc_sinh = 0

def them_hoc_sinh(ten, diem): # ten, diem là biến Local
    global tong_diem, so_hoc_sinh
    
    # Kiểm tra tính hợp lệ bằng biến Local
    if diem < 0 or diem > 10:
        return f"Lỗi: Điểm của {ten} không hợp lệ!"
        
    # Cập nhật dữ liệu hệ thống (Global)
    tong_diem += diem
    so_hoc_sinh += 1
    return f"Đã thêm {ten}."

print(them_hoc_sinh("An", 8.5))
print(them_hoc_sinh("Bình", 9.5))
print(f"Sĩ số: {so_hoc_sinh} | ĐTB: {tong_diem/so_hoc_sinh}")

Thông điệp chính

  • Hiểu rõ phạm vi biến giúp tránh lỗi code ngớ ngẩn.
  • Biết dùng đúng chỗ giúp viết chương trình chuyên nghiệp hơn, dễ quản lý bộ nhớ.
