Tại sao phải quan tâm "Phạm vi"?

Nếu mọi thứ là Global?

Hãy tưởng tượng một thành phố không có cửa nhà, ai cũng có thể lấy hoặc sửa đồ của người khác. Sự hỗn loạn sẽ xảy ra!

  • Xung đột tên biến khi code dài.
  • Dữ liệu dễ bị sửa đổi ngoài ý muốn.
  • Tốn bộ nhớ vô ích vì biến tồn tại mãi mãi.

Giải pháp của Python

Chia không gian sống của biến thành các cấp bậc (Scopes):

  • Local (Cục bộ): Khu vực riêng tư, an toàn.
  • Global (Toàn cục): Khu vực công cộng, dữ liệu chia sẻ.

Giải thích chuyên sâu

Khi mới học, chúng ta hay khai báo biến ngoài hàm cho tiện. Nhưng với dự án lớn, điều đó gây thảm họa. Phạm vi giúp đóng gói và cách ly dữ liệu, máy tính biết khi nào tạo vùng nhớ và khi nào giải phóng.

1. Biến cục bộ (Local Variable)

Định nghĩa & Đặc điểm

Là biến được sinh ra bên trong một hàm. Nó là "tài sản riêng" của hàm đó.

  • Tuổi thọ: Chỉ tồn tại khi hàm bắt đầu chạy.
  • Cái chết: Bị xóa ngay khi hàm kết thúc.
  • Bảo mật: Code bên ngoài không thể chạm vào.
local_memory.py
def tinh_luong(ngay_cong):
    thuong = 500000  # Local variable
    return (ngay_cong * 200000) + thuong

print(tinh_luong(22))
# print(thuong)  # NameError: biến local không tồn tại ngoài hàm

Call Stack & Frame

Khi gọi hàm, Python tạo một "khung ngăn xếp". Biến thuong được cất trong khung đó. Hàm kết thúc → khung bị hủy → giải phóng RAM ngay lập tức.

2. Biến toàn cục (Global Variable)

Định nghĩa & Đặc điểm

Khai báo ở ngoài cùng của file code. Là "tài sản chung".

  • Tuổi thọ: Tồn tại đến khi tắt chương trình.
  • Đọc dữ liệu: Mọi hàm đều nhìn thấy và đọc được.
  • Ghi dữ liệu: Cần từ khóa global nếu muốn sửa.
global_read.py
he_so_pi = 3.14159  # Biến Global

def tinh_chu_vi(ban_kinh):
    return 2 * he_so_pi * ban_kinh

def tinh_dien_tich(ban_kinh):
    return he_so_pi * (ban_kinh ** 2)

3. Hiện tượng Shadowing (Che khuất)

shadowing.py
message = "Hello Global"

def say_something():
    message = "Hi Local"
    print("Trong hàm:", message)

say_something()
print("Ngoài hàm:", message)

Kết quả:

Trong hàm: Hi Local
Ngoài hàm: Hello Global

Biến Global không hề bị thay đổi!

Phân tích

Python khi thấy phép gán = bên trong hàm sẽ mặc định tạo biến Local mới. Biến Local "che khuất" biến Global cùng tên.

4. Quy tắc tìm kiếm biến: L.E.G.B

L Local

Tìm trong nội bộ hàm đang chạy trước tiên.

E Enclosing

Tìm ở hàm bao ngoài (nếu có hàm lồng nhau).

G Global

Tìm ở cấp độ file code.

B Built-in

Tìm trong thư viện gốc của Python.

Hình dung

Giống như tìm chìa khóa: trong túi quần → trong phòng → phòng khách chung → ra siêu thị mua mới. Python tìm từ trong ra ngoài.

5. Cái bẫy "UnboundLocalError"

bug_demo.py
count = 10

def increase():
    print(count)        # Dòng 4
    count = count + 1   # Dòng 5

increase()

LỖI

UnboundLocalError: local variable 'count' referenced before assignment

Giải thích

Python thấy phép gán count = ... nên xác định count là biến Local. Khi chạy print(count), nó tìm biến Local nhưng chưa được gán → lỗi.

6. Từ khóa global

fix_bug.py
count = 10

def increase():
    global count
    print("Cũ:", count)
    count = count + 1
    print("Mới:", count)

increase()
print("Ngoài hàm:", count)

Kết quả:

Cũ: 10
Mới: 11
Ngoài hàm: 11

Lời khuyên

Hạn chế dùng global để tránh rối code. Thay vào đó hãy truyền tham số và dùng return.

7. Bài Tập Sáng Tạo: Quản Lý Điểm

quan_ly_hoc_sinh.py
tong_hoc_sinh = 0
tong_diem = 0.0
log_actions = 0

def them_diem(ten, diem):
    global tong_hoc_sinh, tong_diem, log_actions
    log_actions += 1
    if diem < 0 or diem > 10:
        return f"❌ Lỗi: Điểm {diem} của {ten} vô lý!"
    tong_hoc_sinh += 1
    tong_diem += diem
    return f"✅ Đã thêm {ten} ({diem} điểm)"

def tinh_trung_binh():
    return tong_diem / tong_hoc_sinh if tong_hoc_sinh else 0

print(them_diem("Nguyễn Văn A", 8.5))
print(them_diem("Lê Thị B", 9.0))
print(them_diem("Hacker C", -5))
print(f"👉 Thống kê: {tong_hoc_sinh} HS. Điểm TB: {tinh_trung_binh():.2f}. Lượt thao tác: {log_actions}")

TỔNG KẾT BÀI HỌC

Local

  • Sống và chết trong hàm.
  • Đảm bảo an toàn, độc lập.
  • Ưu tiên sử dụng tối đa.

Global

  • Tồn tại suốt chương trình.
  • Dùng global để sửa giá trị.
  • Hạn chế lạm dụng.

Best Practice

Theo PEP-8, hằng số toàn cục nên VIẾT_HOA (VD: MAX_USERS = 100), biến Local viết thường. Giúp đồng đội dễ nhận biết phạm vi.
